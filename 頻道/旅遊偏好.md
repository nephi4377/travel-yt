# 旅遊偏好（本人）

依 2026-08 問卷整理，2026-08-23 補：吃要當地名物、同行人數不固定。

速記：`1B 2B 3A 4C 5B 6A 7A 8B 9A 10C`

## 一句話

找在地人真的在用的地方；錢少但體驗密；跟自己對得上；旅行優先，有感才拍。  
吃要吃到**那個地方人人都認識的那幾樣**，不是隨便填肚子，也不是網紅店。

## 個性備註（企劃時可對）

務實的深度旅人：要在地日常，但獨特性須對得上自己，不為冷門而冷門。  
會協調（順路熱門、同行一半一半），對浪費敏感（錢／時間換體驗密度）。  
節奏慢、範圍窄、準備剛好；體驗優先於鏡頭。

## 同行（每次不同，不要預設五人）

可能是：兩人（和太太）、帶兩個女兒、再加父母、再加朋友，或別的組合。  
**不要把「五人」寫進程式或鐵則。** 每趟開頭先寫這次幾人、誰去。

不變的規則：

- 不硬拆隊。
- 不為鏡頭讓人空等。
- 人數多時，談行程仍爭取「一半自己想走的線、一半配合大家」；兩人就可以走得更像自己的線。
- 帶長輩或小孩：一天一塊更要守，少爬、少趕、吃飯優先找坐得住的店。

## 吃飯（在地名物，不是網紅、也不是隨便）

在**食堂、市場、巷口老店、空桌就進**的地方，把當地代表性食材／日常名物吃到。  
不追排名第一、不排網紅店、不把評價當主軸。店可以普通，菜要對。

「名物」＝當地人自己也吃、外地人一提就知道的那幾樣。例如：

| 地方 | 這趟至少要碰到的（正餐） | 不當正餐主軸 |
|------|--------------------------|--------------|
| 越南 | 河粉、法式麵包夾肉（越南麵包）、烤米線／炭烤豬肉米線一類 | 蛋咖啡當加菜可以；不要整天只喝網美咖啡 |
| 韓國 | 馬鈴薯排骨湯、泡菜（餐桌上就有）、豬肉湯飯／市場海鮮 | 人蔘雞、人蔘茶是補品／一餐點綴，不要當每天主題 |
| 日本 | 拉麵、炸豬排 | 不追百名店排隊 |

成功：回來講得出「這地方的味道是什麼」，不是「吃了一家很紅的店」。  
失敗：貴、等很久、菜跟當地日常無關；或便宜但全是漢堡薯條。

## 偏好（問卷）

| 面向 | 選擇 |
|------|------|
| 深層次 | 當地人在用、遊客較少的點 |
| 大眾景點 | 順路可去，不當主軸、不多拍 |
| CP 值 | 錢少但體驗密度高 |
| 獨特性 | 跟個性／興趣對得上，不為特別而特別 |
| 同行 | 一半熱門、一半自己想走的線（人數多時特別要談） |
| 吃飯 | 見上：在地食堂吃名物 |
| 節奏 | 一條線慢慢走，少切換區域 |
| 行前 | 關鍵 2–3 點＋備案，細節現場補 |
| 拍 vs 玩 | 旅行本身；有感才拍 |
| 回來值得 | 花的錢／時間很值 |

## 企劃時怎麼用

- **選點**：優先「當地日常用途」＞網紅打卡；熱門點最多當順路或半日妥協。
- **一天**：同一區一條線，不要跨城趕場。
- **吃**：先寫這趟「一定要碰到的名物」，再為每餐找食堂／市場三選一；不把評價排名當主軸。
- **預算感**：少花錢換到濃的體驗＝成功；貴但空洞＝失敗。
- **拍**：不為鏡頭改行程；沒感覺就不要硬拍。
- **同行**：先問這趟誰去；規則見上面，不要複製上趟人數。
