# 旅遊 YouTube 頻道資料庫

**人怎麼做一集：** 先看 [`工作流程.md`](工作流程.md)。  
**怎麼玩／選點：** 先看 [`頻道/旅遊偏好.md`](頻道/旅遊偏好.md)（之後每趟行程都要對這份）。

這裡只放**文字與小圖**：定位、企劃、腳本、標題、發布紀錄。

原始影片、剪輯專案請放雲端硬碟或本機，不要 push 上來。

## 資料夾怎麼用

| 資料夾 | 放什麼 |
|--------|--------|
| `頻道` | 頻道定位、**旅遊偏好（必參）**、片頭片尾規格、固定話術 |
| `靈感` | 還沒做成片子的點子 |
| `企劃` | 每一集一份資料夾：腳本、拍攝清單、標題選項 |
| `發布` | 已上片的標題、描述、標籤、連結 |
| `素材連結` | 指向雲端影片／照片的路徑（不是檔案本身） |
