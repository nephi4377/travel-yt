# 旅遊 YouTube 頻道資料庫

**人怎麼做一集：** 先看 [`工作流程.md`](工作流程.md)。

這裡只放**文字與小圖**：定位、企劃、腳本、標題、發布紀錄。

原始影片、剪輯專案請放雲端硬碟或本機，不要 push 上來。

## 資料夾怎麼用

| 資料夾 | 放什麼 |
|--------|--------|
| `頻道` | 頻道定位、片頭片尾規格、固定話術 |
| `靈感` | 還沒做成片子的點子 |
| `企劃` | 每一集一份資料夾：腳本、拍攝清單、標題選項 |
| `發布` | 已上片的標題、描述、標籤、連結 |
| `素材連結` | 指向雲端影片／照片的路徑（不是檔案本身） |

新一集：複製 `企劃/_模板`，改成日期＋主題，例如 `2026-08-名古屋一日`.

## GitHub

建議設成 **Private**。未公開腳本、未拍點子不適合公開。

本機已是 git 倉庫。第一次推上去：

1. 在 GitHub 新增空倉庫 `travel-yt`（勾 Private，不要加 README）
2. 在這個資料夾執行：

```
git remote add origin https://github.com/nephi4377/travel-yt.git
git branch -M main
git push -u origin main
```
