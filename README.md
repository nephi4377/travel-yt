# 旅遊 YouTube 頻道資料庫

這個 GitHub repo 是旅遊企劃、手機旅遊頁、已採用圖資及迭代決策的主要保存處。原始影片與剪輯專案仍另存，圖片與地圖版本則需保存於對應企劃資料夾並建立索引。

開始修改前先讀 [AGENTS.md](AGENTS.md)，並拉取 `main` 最新版本；本機副本可能落後。

手機站（GitHub Pages）：[豪哥旅遊手冊](https://nephi4377.github.io/travel-yt/)
