# 2026/11 上海・江南跟團｜旅行社正式團行程

日期：**11/23–11/29（7 日）**。以下依使用者提供的旅行社 PDF「11-12月秋楓潮樂之城7日」整理；實際班機、飯店與行程順序仍以旅行社出發前通知為準。

## 航班
- 去程：長榮航空 **BR706**，高雄 → 上海，16:50 起飛、19:05 抵達。
- 回程：長榮航空 **BR705**，上海 → 高雄，20:05 起飛、22:20 抵達。

## 行程特色
- 全程無購物站（旅行社註明不含特色商店）。
- 全程無自費項目。
- 中國上網卡每人一張（7G/8天）、每日礦泉水。
- 安排大閘蟹，部分晚餐標示 RMB 150–200。

## 每日行程

### D1｜高雄 → 上海
- 抵達上海。
- 晚餐：機上簡餐＋迎賓水果。
- 住宿：浦東溫德姆花園酒店／或同級。

### D2｜上海 → 臨安青山湖 → 徑山寺
- 青山湖水上森林公園（船遊）。
- 徑山寺。
- 早餐：酒店；午餐：中式合菜 RMB 60；晚餐：豪華美食＋大閘蟹（一公一母）RMB 200。
- 住宿：青山湖美爵酒店／或同級。

### D3｜上海 → 紹興
- 柯岩風景區：柯岩古鎮、魯鎮。
- 倉橋直街。
- 蘭亭。
- 早餐：酒店；午餐：中式合菜 RMB 60；晚餐：豪華美食宴 RMB 150。
- 住宿：蘇寧希爾頓酒店／或同級。

### D4｜紹興 → 鹽官潮樂之城
- 沈園。
- 黃酒小鎮。
- 潮樂之城：鹽官潮牆、鹽官報社、北門潮集、御碼頭等。
- 晚間入住古城景區。
- 早餐：酒店；午餐：黃酒宴 RMB 60；晚餐：古城集市自理。
- 住宿：潮樂之城主唱音樂度假酒店／或同級。

### D5｜潮樂之城 → 嘉興 → 南潯 → 湖州
- 清晨漫步潮樂之城。
- 嘉興南湖賞紅楓＋遊船。
- 南潯古鎮：嘉業堂藏書樓、小蓮莊、搖櫓船。
- 湖州地標景觀夜景。
- 早餐：酒店；午餐：中式合菜 RMB 60；晚餐：豪華美食宴 RMB 200。
- 住宿：南潯希爾頓酒店／或同級。

### D6｜湖州 → 上海
- 上海共青森林公園。
- 沉浸式宮廷宴。
- 滴水湖洲際酒店。
- 早餐：酒店；午餐：宮宴 RMB 398（3–4 排）；晚餐：豪華美食宴 RMB 150。
- 住宿：滴水湖洲際酒店／或同級。

### D7｜滴水湖 → 上海機場 → 高雄
- 滴水湖度假區／飯店設施。
- 朵雲書院。
- 南匯嘴觀海公園。
- 上海比斯特購物村。
- 前往上海機場搭 BR705 返回高雄。
- 早餐：酒店；午餐：珠蚌宴 RMB 60；晚餐：機上輕食。

## 跟團管理提醒
- 賞楓／銀杏受天候影響，旅行社不保證實際葉況。
- 團體行程順序、飯店與航班可能因現場狀況調整。
- 此檔保存「旅行社排定內容」；個人偏好與現場調整另記於 `行程.md`。
