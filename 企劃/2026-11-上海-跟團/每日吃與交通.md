# 上海跟團：名物怎麼補＋移動備註

團餐常常是桌菜、口味偏淡或偏觀光。你要的是**當地人人認識的那幾樣**，在食堂、早餐店、巷口吃，不追網紅店、不排一小時。

## 這趟至少要碰到

1. **小籠包或湯包** — 皮薄、湯在裡頭。早餐店、老店比景區店容易對。  
2. **生煎** — 鍋貼那類、底部煎過、有湯汁。上海日常早餐。  
3. **本幫味道** — 濃油赤醬的飯菜、或紅燒一類。團餐若有就吃；沒有就晚上找食堂。

加菜：油條豆漿、蔥油拌麵、腌篤鮮（看季節與店）。  
不當主軸：外灘景觀餐廳、網紅奶茶排一小時。

排隊約 40 分鐘換隔壁同類型。景區裡的「百年第一」常常是價高、隊長。寧可回飯店那條路找還在送早點的店。

## 移動（團車為主）

白天移動由旅行社安排。下列為**約略車程**（公開導航常見值），供心裡有數，不當準點：

| 路段 | 約略 |
|------|------|
| 上海 → 臨安青山湖 | 2–2.5 h |
| 臨安一帶 → 紹興 | 1.5–2.5 h（**待確認**出發飯店） |
| 紹興 → 鹽官 | 1–1.5 h |
| 鹽官 → 嘉興南湖 | 45–70 min |
| 嘉興 → 南潯 | 50–80 min |
| 南潯／湖州 → 上海共青森林公園 | 1.5–2.5 h |
| 共青森林公園 → 滴水湖 | 1–1.5 h |
| 滴水湖 → 浦東機場 | 40–60 min |

航班日自己預留出境安檢緩衝；機場日聽領隊集合，不自行改點。

## 依住宿提案的吃喝錨（三選一搜尋）

飯店均可能改**同級**；以下以團表提案店名為半徑。店名未逐家電話實地核對者標 **待確認**——現場用地圖搜尋詞＋看人潮／價位。

搜尋用字：`生煎`、`小籠`、`湯包`、`本幫菜`、`麵館`。

### D1 夜／D2 早｜浦東溫德姆花園酒店或同級
- **錨：** [Maps・酒店](https://www.google.com/maps/search/?api=1&query=%E4%B8%8A%E6%B5%B7%E6%B5%A6%E4%B8%9C%E6%B8%A9%E5%BE%B7%E5%A7%86%E8%8A%B1%E5%9B%AD%E9%85%92%E5%BA%97)  
- **候選方向：** ① 酒店步行圈搜「生煎」② 搜「小籠包」③ 便利店＋明早再補。  
- D1 抵達晚：優先睡覺；名物可挪到 D6／D7。

### D2 夜／D3 早｜青山湖美爵或同級（臨安）
- **錨：** [Maps・青山湖美爵](https://www.google.com/maps/search/?api=1&query=%E9%9D%92%E5%B1%B1%E6%B9%96%E7%BE%8E%E7%88%B5%E9%85%92%E5%BA%97)  
- **候選：** 酒店早餐為主；晚已有蟹宴。附近小吃選擇可能薄——**待確認**；不為名物打車去杭州城。

### D3 夜／D4 早｜紹興蘇寧希爾頓或同級
- **錨：** [Maps・蘇寧希爾頓紹興](https://www.google.com/maps/search/?api=1&query=%E7%BB%8D%E5%85%B4%E8%8B%8F%E5%AE%81%E5%B8%8C%E5%B0%94%E9%A1%BF%E9%85%92%E5%BA%97)  
- **候選：** ① 飯店圈「麵館」② 「小吃」③ 便利補給。紹興不是上海名物主戰場。

### D4 晚（自理）｜鹽官主唱音樂度假酒店或同級
- **錨：** [Maps・潮樂之城主唱酒店](https://www.google.com/maps/search/?api=1&query=%E6%BD%AE%E4%B9%90%E4%B9%8B%E5%9F%8E%E4%B8%BB%E5%94%B1%E9%9F%B3%E4%B9%90%E5%BA%A6%E5%81%87%E9%85%92%E5%BA%97)  
- **候選方向（古城集市）：** ① 缸肉／當地熱食 ② 宴球或魚圓一類（看攤）③ 簡單麵飯吃飽。具體店名 **待確認**——以現場開放攤位為準，不追網紅店。  
- 這晚是「自理正餐」窗口，優先吃飽＋試在地味。

### D5 夜／D6 早｜南潯希爾頓或同級
- **錨：** [Maps・南潯希爾頓](https://www.google.com/maps/search/?api=1&query=%E5%8D%97%E6%B5%94%E5%B8%8C%E5%B0%94%E9%A1%BF%E9%85%92%E5%BA%97)  
- **候選：** ① 酒店早餐 ② 飯店外「本幫／浙菜」搜尋 ③ 古鎮外緣食堂（避開景區核價）。  
- 古鎮內搖櫓船後若餓：設 40 分鐘排隊上限。

### D6 夜／D7 早｜滴水湖洲際或同級
- **錨：** [Maps・滴水湖洲際](https://www.google.com/maps/search/?api=1&query=%E6%BB%B4%E6%B0%B4%E6%B9%96%E6%B4%B2%E9%99%85%E9%85%92%E5%BA%97)  
- **候選：** 臨港餐飲密度低於市區——① 酒店餐 ② 滴水湖／港城新天地商圈搜「生煎」「小籠」③ 機場航廈輕食。具體店 **待確認**。  
- **上海名物收尾日：** 能補生煎／小籠就補；趕機不硬補。

### 上海連鎖方向（非唯一正解）
若落在市區且時間允許，可搜常見連鎖如「小楊生煎」作早餐型參考（分店多、品質看分店；**不當必朝聖**）。景區第一名店可跳過。

## 時段口令

| 時段 | 怎麼補名物 |
|------|------------|
| 飯店早餐是西式 | 出門前或集合前 20 分鐘找生煎／豆漿（若集合太早就放棄，晚上補） |
| 團午餐桌菜 | 吃飽。記住有沒有本幫；沒有就晚餐補 |
| 購物／奧特萊斯站 | 不要用購物站零食當正餐 |
| 晚上自由 | 飯店走路範圍三選一 |
| 整天外埠 | 車上備水；名物改回上海那幾晚補 |

「團餐先吃飽。缺的那一味晚上補，不跟景區隊伍。」
