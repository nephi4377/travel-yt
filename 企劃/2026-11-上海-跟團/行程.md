# 上海跟團（11/23–11/29）

## 這趟跟釜山、河內不一樣

旅行社賣的是一套白天：車、導遊、景點停留、常常含幾頓餐。  
你的偏好是：一天一塊、在地食堂、名物、少趕。**兩套會打架。** 打架時：

- 白天跟團走（你選了跟團，就不要在車上杯葛每一站）。
- 自費景點、購物站、額外秀：可以拒，用下面口令。
- **吃：** 團餐若沒有上海日常名物，用早餐、自由時段、晚上補。不要為了生氣整團。
- **拍：** 有感再拍「人怎麼被帶著走」或晚上自己走路；不要為了外灘燈光改睡。團的打卡時間不必全拍。

成功：回來講得出上海的味道（小籠／生煎／濃油赤醬一類）跟團有沒有給到；有沒有整天只在車上。  
失敗：自費全買、名物沒吃到、為了鏡頭跟團吵。

誰去尚未寫。跟團通常人數已定；仍不要在別的檔複製「五人」。

## 你還能決定的事

**出發前**

- 把團行程貼進 `團行程.md`（幾點集合、幾頓團餐、哪幾天自由、有沒有蘇杭等外埠）。
- 外埠（蘇州、杭州、烏鎮等）一天若在車上：心裡當「那天體驗密度低」，不要再加夜場。
- 簽證／通行證、零錢、地圖 App：跟團仍要自己能走路回飯店。

**現場每一天**

1. 早上若自理：用名物當早餐（生煎、豆漿、小籠），不要只吃飯店歐式。
2. 團餐：能點就點本幫、湯包；不能點就吃飽，晚上補。
3. 購物站：不需要就不進店，在車上或門口等（不拆隊到消失，跟導遊說在哪等）。
4. 晚上若自由：只走**飯店那一塊**，吃一頓名物，不另開迪士尼夜場。
5. 迪士尼、夜遊船、黃浦江遊船若是自費：想去就去，當「熱門一半」；不想去就拒，把力氣留給吃飯與睡覺。

**口令**

- 「自費我先不算，謝謝。」
- 「我在車上／門口等，不進店。」
- 「晚上我只在飯店附近吃，不跟夜遊。」

## 跟偏好會撞車的典型站

| 團常去 | 你怎麼看 |
|--------|----------|
| 外灘、東方明珠外觀 | 順路熱門，當看一眼；不要當主軸拍片 |
| 城隍廟／豫園周邊 | 極觀光；若團停，走一圈看人流即可。名物小籠在這裡常更貴更排——可看、可改去住的附近早餐店吃 |
| 南京路 | 買東西可以，不當朝聖 |
| 博物館 | 若團排了，當室內休息；有感再看，不求看完 |
| 蘇杭一日 | 密度低；當天以不餓、不吵為成功 |
| 迪士尼 | 熱門且整天；跟「在地日常」不合。團若含，當天就接受是遊樂園日，名物改早或晚補 |

不合的不要在車上講導遊壞話當節目。自己記：哪一段是妥協。

## 團表來了以後要補的格子

貼表之後，每一天加三行即可：

- 團餐幾頓、能不能點菜  
- 哪一餐改由你找生煎／小籠／本幫  
- 晚上自由還是仍跟團  

沒表之前不要假裝已知道每天幾點。
