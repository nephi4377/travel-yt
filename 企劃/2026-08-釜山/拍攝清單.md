# 拍攝清單

## 定場與轉場

- [ ] 片頭定場：市場入口／碼頭／電車出站口（擇一，10–20 秒穩）
- [ ] 空景：港口遠景、天際線、橋側面
- [ ] 腳步／路面近景（轉場用）
- [ ] 結尾畫面：黃昏或燈亮後的港區

## 市場（札嘎其一帶）

- [ ] 外圍攤位全景（人流，不要只拍招牌）
- [ ] 搬貨／推車／洗魚水聲（跟 20–40 秒）
- [ ] 手部近景：秤、刀、冰塊、塑膠籃
- [ ] 店家與客人對話距離感（遠一點拍，勿打擾）
- [ ] 你自己走路進市場的主觀鏡頭（可手持）

## 走路／橋／海岸

- [ ] 南浦街道走到港邊的連續感（不必一鏡到底，切幾段即可）
- [ ] 影島大橋或沿海步道：風聲明顯的一段
- [ ] 對岸高樓 vs 港口作業的對照畫面
- [ ] 坐一下或靠欄杆的休息鏡頭（節奏緩衝）

## 吃飯

- [ ] 店門口／座位（說明「停在哪」）
- [ ] 點餐或上菜過程
- [ ] 蒸汽／湯碗／第一口
- [ ] 店外或窗邊環境音收尾

## 備用（有餘力再拍）

- [ ] 電車或巴士窗景
- [ ] 小巷洗衣／電線／住家門牌（日常細節）
- [ ] 雨天備案：室內市場走廊、咖啡店窗景
