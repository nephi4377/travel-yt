# 2026/12 土耳其（跟團）

日期：**2026/12/12–12/21（10 日；12/20 自伊斯坦堡返台，D10 抵達桃園）**。

旅行社行程主題：五星土耳其、熱氣球升空、番紅花城、艾菲索斯古城、伊茲密爾、卡帕多奇亞連泊。

## 航班
- 去程：土耳其航空 **TK125**，2026/12/12 10:15 台北桃園 → 伊斯坦堡，直飛。
- 桃園出發航廈：**第二航廈 T2**（目前查得；出發前仍須再次確認）。
- 回程：土耳其航空 **TK124**，2026/12/20 17:15 伊斯坦堡 → 台北桃園。
- 實際航班時間依旅行社與航空公司最終確認為準。

## 重點
- 贈送熱氣球行程；若卡帕多奇亞因天候未能搭乘，旅行社說明會嘗試隔日候補，仍未成功則改棉堡；若再因客滿或天候取消，依旅行社條款退費。
- 贈送博斯普魯斯海峽包船。
- 卡帕多奇亞連泊 2 晚。
- 包含番紅花城鄂圖曼風格民宿體驗。
