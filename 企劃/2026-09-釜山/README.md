- 排隊超過約 40 分鐘就換，不為單一店跨區折返。
- 9/8 南浦／札嘎其；9/9 海雲台；9/11 西面；9/12 只去機場。

- 9/9 廣安里可取消；若 9/10 最終仍保留太宗台則不依賴 `다누비열차`；9/11 先確認 `고짚 서면본점` 五人座，再啟動第二順位。
