## 已固定的現場原則

- 五人同行，住宿 Booking the Bay。
- 豬肉湯飯整趟最多一次；不吃生魚片；海鮮以全熟為主。
- 排隊超過約 40 分鐘就換，不為單一店跨區折返。
- 9/8 南浦／札嘎其；9/9 海雲台；9/11 西面；9/12 只去機場。
- **KMA 目前 9/7～9/9 趨勢：多雲、降雨機率約 20%，釜山約 23～29°C。** 目前不需要交換 9/8 南浦與 9/9 海雲台；真正逐時風雨仍留到 9/5～9/6 再判斷。
- **9/10 仍在重新收斂**：目前較傾向 `Busan Premium Outlets → 東萊虛心廳 → 西面`，因同行者明確偏好真正 Outlet，且太宗台不是必去。購物袋與出發交通風險已有 Plan B；正式切換仍等 9/3–9/5 天氣、營業與交通最後狀態一次決定。
- 9/9 廣安里可取消；若 9/10 最終仍保留太宗台則不依賴 `다누비열차`；9/11 先確認 `고짚 서면본점` 五人座，再啟動第二順位。
- 越接近出發越以穩定執行為優先，不為自動迭代增加景點。

海雲台是 **9/9 出去玩**，不塞進 9/8 港區主拍攝日。
