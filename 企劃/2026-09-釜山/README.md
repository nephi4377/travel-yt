## YT／行程固定規格：每日都要有吃飯推薦

此規格為**不可省略欄位**，適用 9/7–9/12 每一天，也適用之後新增的任何行程日。網站、`行程.md`、每日口白與拍攝企劃在整理或精簡時，都不得把「吃飯推薦」刪掉。

每個行程日的「🍽 吃飯推薦」至少包含：

- **當日首選餐廳／餐型**：優先沿用已查證、已鎖定的店，不因版面精簡而消失。
- **同區備選**：原則上至少 1 個；候位 >40 分、臨休、五人無法同桌時可立刻換。
- **五人點餐策略**：份量、套餐／單點、是否適合共享、需要先問的事項。
- **現場必要資訊**：韓文店名、地址、營業／休息提醒、價位錨點；有電話或訂位資訊則一併保留。
- **飲食限制**：不吃生魚片、海鮮全熟優先、豬肉湯飯整趟最多一次。
- **不跨區追店**：餐廳失效時只在當天活動區域內換店，不為單一餐廳破壞主線。
- **YT 拍攝最小素材**：店外招牌／韓文店名、菜單或價格、食物近拍、第一口真實反應、離場一句；不可預寫「很好吃」。

即使是抵達日或返程日，也必須有可執行的吃飯方案，例如「首選／附近備案／便利商店或機場方案」，不可顯示空白或直接省略。
