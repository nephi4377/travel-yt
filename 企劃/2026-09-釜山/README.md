## 已固定的現場原則

- 五人同行，住宿 Booking the Bay。
- 豬肉湯飯整趟最多一次；不吃生魚片；海鮮以全熟為主。
- 排隊超過約 40 分鐘就換，不為單一店跨區折返。
- 9/8 南浦／札嘎其；9/9 海雲台；9/11 西面；9/12 只去機場。
- **KMA 2026-08-31 06:00 已正式涵蓋 9/10**：釜山 9/7～9/10 目前都以多雲、降雨機率約 20% 為主；9/10 約 24–29°C。9/8、9/9 不需要交換日期。
- **9/10 已正式收斂**：`Booking the Bay → Busan Premium Outlets → 東萊虛心廳 → 西面`。太宗台＋感地烤貝＋Spa Land 退出現場主線，不再維持兩套半成品。
- 9/10 五人交通優先大型計程車／兩台一般車；Outlet 買太多時，虛心廳是可刪節點，直接往西面／飯店，不為泡湯折返。
- 9/9 廣安里可取消；9/11 先確認 `고짚 서면본점` 五人座，再啟動第二順位。
- 越接近出發越以穩定執行為優先，不為自動迭代增加景點。
- YouTube 9/10 的口白、拍攝清單與標題方向已改成 Outlet＋東萊線；實際體驗前不預寫「超好買」「最好吃」。
- 上片前若要使用「最大、第一、最有名、必吃、必去」等資訊型字眼，先看 `口白查證清單.md`；查不到近期可靠來源就改成保守說法。
