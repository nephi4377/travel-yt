# 拍攝清單（9/8 港區）

備忘用。旅行優先，五人在玩，順手拍。勾不到不補拍、不改路。  
每個段落看／聽／講什麼：`細節.md`。

這集只跟 **南浦 → 市場 → 札嘎其外圍**（走得動、風勢舒服再過橋）。  
海雲台、膠囊車、甘川、白淺灘、五六島、松島纜車：**不進這集**。

成功三題（回來能答就夠）：市場當時在忙什麼；港邊當時風勢如何（沒去港邊就跳過）；為什麼進那家店。

## 出門前

- [ ] 電、空間、麥克風開、鏡頭乾淨
- [ ] 心裡只有三件事：手與水、現場風勢、為什麼坐下

## 定場｜一定要拍一個就好，10–20 秒穩

- [ ] 市場入口／出站口，人走進去

### 有空再拍｜風弱、不影響五人才拍

- [ ] 港口遠景／天際線；若陣風強、沿岸有警示或站著已不舒服，直接不拍

## 市場（札嘎其外圍為主；國際市場當走廊走過）

- [ ] 人流全景（不要只拍招牌）
- [ ] 跟一個動作 20–40 秒：搬貨／推車／洗魚沖水
- [ ] 手：秤、刀、冰、塑膠籃
- [ ] 遠一點的對話距離（勿擋攤、勿拍臉特寫）
- [ ] 你自己走進市場（可手持）

## 走路／橋｜有空再拍，風強整段取消

- [ ] 南浦走到港邊的連續感（只有原動線本來就會經過才留）
- [ ] 影島大橋或沿海風聲一段
- [ ] 近處吊車／船 vs 對岸樓
- [ ] 靠欄杆停一下

> 以上四項全部不是剪輯必要素材。9/8 當天若陣風強、沿岸有警示、下雨使停留不舒服，或五人任何一位不想在港邊久站，就全部跳過；市場／室內主線照走。

## 吃飯（五人訂位的店，不要拍成「隨便走進」）

- [ ] 門口或座位（停在哪）
- [ ] 點餐或上菜整段
- [ ] 蒸汽／湯碗／第一口
- [ ] 心裡一句：餓了／空桌／被帶進來／聞味道進來
- [ ] 店外或窗邊環境音收尾

## 結尾（擇一）

- [ ] 黃昏或燈亮的港（飯店旁邊北港就夠，不要再跑夜景點；風強就改室內／飯店一句收尾）

## 備用（有餘力、沒擋大家）

- [ ] 車窗或地鐵窗
- [ ] 小巷電線／住家門（遠拍）
- [ ] 下雨：市場騎樓、室內走道（取消過橋）

## 現場不要做

- 為了鏡頭讓五人停下來等
- 跟到攤商臉前、擋推車
- 為天空膠囊、打卡村改路
- 開頭預告「必去景點」、邊走邊報站名
- 為港面／橋景在強風或警示下硬拍

# 全程拍攝防漏｜9/7–9/12 最小素材鏈

> 這不是新增拍攝量，而是「每個核心停靠點只要有這一串，就足夠剪」。漏一兩項不用補拍，更不能為補鏡頭改家庭動線。

## 每個核心餐廳／景點，一定要拍

1. **抵達／外觀**：3–5 秒，讓觀眾知道到了哪裡。
2. **Wide shot**：環境 5–10 秒，一段就夠；若該 Wide shot 需要在強風、雨勢或不舒服位置久站，直接省略。
3. **人物**：五人中至少一個自然反應，不重演。
4. **辨識細節**：正式韓文招牌、入口或地址其中一個。
5. **價格／菜單**：餐廳至少留一個可讀畫面；景點有票價才拍。
6. **核心體驗**：吃、走、泡、看海、購物的主動作。
7. **第一反應**：吃第一口／第一次看到海／泡完出來／買完集合的真實一句。
8. **離場總結**：10–20 秒；不必評分，只講「值不值得今天這樣安排」。

## 每日最小檢查

### 9/7 抵達
- [ ] 金海抵達牌
- [ ] 五人＋行李／叫車
- [ ] Booking the Bay 外觀或進房
- [ ] 晚餐招牌＋價格／菜單＋第一口；若便利商店就拍戰利品
- [ ] 回房一句「今天結束」即可

### 9/8 南浦／市場／札嘎其｜主拍日
- [ ] 市場入口／出站定場擇一
- [ ] 市場人流＋一段作業動作＋秤／冰／水／推車細節
- [ ] 密麵或實際午餐：招牌／菜單價格＋第一口
- [ ] 晚餐若進高基本，補韓文招牌＋菜單價格＋第一口＋離店一句
- [ ] 港面／吊車／船／影島大橋全部屬「有空再拍」；風強、下雨、警示或有人累就零成本放棄

### 9/9 海雲台／熟海鮮鍋
- [ ] 海灘第一個 Wide shot
- [ ] 五人坐下來的自然畫面
- [ ] `더명품해물탕` 韓文招牌或入口
- [ ] 菜單／大鍋價格畫面
- [ ] 海鮮鍋煮滾、夾料、第一口真實反應
- [ ] 下午只拍真的有去的「冬柏島或咖啡」；廣安里取消就完全不補
- [ ] 離開海雲台前 10–20 秒總結

### 9/10 Busan Premium Outlets／虛心廳／西面
- [ ] Outlet 抵達外觀／主入口 Wide shot
- [ ] `부산 프리미엄 아울렛` 韓文招牌或正式名稱辨識
- [ ] 2–3 個代表品牌區即可，不逐店巡禮
- [ ] 現場折扣牌或價格標籤至少一個可讀畫面
- [ ] 五人分開逛、集合、戰利品自然畫面
- [ ] 午餐菜單／價格＋上桌
- [ ] Outlet → 東萊交通轉場一段
- [ ] 虛心廳只拍外觀、入口前與泡完離場反應；館內禁拍區不拍
- [ ] 如果因購物袋太多刪虛心廳，直接拍真實決策一句，不補拍別的景點
- [ ] 晚上若去西面，只拍實際吃的店，不為素材再追名店

### 9/11 西面／最後晚餐
- [ ] 西面街區 Wide shot
- [ ] 一段自然採買
- [ ] 最後選定那一家才拍招牌，不拍另外兩家湊素材
- [ ] 菜單／代表菜價格
- [ ] 上桌、第一口、五人自然反應
- [ ] 離店總結＋回房整理行李 5 秒

### 9/12 回程
- [ ] 房間最後一眼或行李關門
- [ ] 車往金海／機場出發牌擇一
- [ ] 片尾口白一次即可，不拍完整機場導覽

## 有空再拍

- 交通車窗／地鐵轉線
- 菜單細節多一個角度
- 五人自然聊天與笑聲
- 招牌與人物同框的 Thumbnail 候選

## 不用特地拍

- 為了縮圖重走一次
- 為了完整介紹每家店拍整本菜單
- 排隊中的陌生人臉部特寫
- 禁止攝影區域
- 已取消的太宗台、感地烤貝、Spa Land、廣安里或影島大橋「補素材」
