# 拍攝清單（9/8 港區）

備忘用。旅行優先，五人在玩，順手拍。勾不到不補拍、不改路。  
每個段落看／聽／講什麼：`細節.md`。

這集只跟 **南浦 → 市場 → 札嘎其外圍**（走得動再過橋）。  
海雲台、膠囊車、甘川、白淺灘、五六島、松島纜車：**不進這集**。

成功三題（回來能答就夠）：市場當時在忙什麼；上橋風大不大（沒過橋就跳過）；為什麼進那家店。

---

## 出門前

- [ ] 電、空間、麥克風開、鏡頭乾淨
- [ ] 心裡只有三件事：手與水、風、為什麼坐下

## 定場（擇一就好，10–20 秒穩）

- [ ] 市場入口／碼頭／出站口，人走進去
- [ ] （可再要）港口遠一點、天際線

## 市場（札嘎其外圍為主；國際市場當走廊走過）

- [ ] 人流全景（不要只拍招牌）
- [ ] 跟一個動作 20–40 秒：搬貨／推車／洗魚沖水
- [ ] 手：秤、刀、冰、塑膠籃
- [ ] 遠一點的對話距離（勿擋攤、勿拍臉特寫）
- [ ] 你自己走進市場（可手持）

## 走路／橋（走不動整段取消）

- [ ] 南浦走到港邊的連續感（手晃也留）
- [ ] 影島大橋或沿海：風聲明顯的一段
- [ ] 近處吊車／船 vs 對岸樓
- [ ] 靠欄杆停一下

## 吃飯（五人訂位的店，不要拍成「隨便走進」）

- [ ] 門口或座位（停在哪）
- [ ] 點餐或上菜整段
- [ ] 蒸汽／湯碗／第一口
- [ ] 心裡一句：餓了／空桌／被帶進來／聞味道進來
- [ ] 店外或窗邊環境音收尾

## 結尾（擇一）

- [ ] 黃昏或燈亮的港（飯店旁邊北港就夠，不要再跑夜景點）

## 備用（有餘力、沒擋大家）

- [ ] 車窗或地鐵窗
- [ ] 小巷電線／住家門（遠拍）
- [ ] 下雨：市場騎樓、室內走道（取消過橋）

## 現場不要做

- 為了鏡頭讓五人停下來等
- 跟到攤商臉前、擋推車
- 為天空膠囊、打卡村改路
- 開頭預告「必去景點」、邊走邊報站名
