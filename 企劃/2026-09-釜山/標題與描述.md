# 標題與描述

> 用途：先把每天的影片主題與包裝方向準備好，上片前再依實際體驗、素材強弱與真實反應改最後版本。不要在還沒吃、還沒走之前寫「最好吃」「必去」「第一名」。

## 共通原則

- 標題像旅行日記，不像觀光局或廣告。
- 一支片只抓一個主要記憶點；不要把當天所有景點都塞進標題。
- 可用「五個人」「慢慢走」「臨時取消」「真的有累」這種真實家庭旅行線索。
- 海雲台是 9/9，不寫進 9/8 港區主片標題。
- 9/10 尚未正式鎖線；以下同時保留舊主線與 Outlet 候選，等正式切線後刪掉不用的一組。
- Thumbnail 文字若要加，控制在 4–8 個中文字，避免和標題重複。

# 9/7｜抵達釜山：先把一家五口安頓好

## 標題方向

1. 五個人晚上才到釜山｜第一天只想順利進房
2. 釜山第一晚｜不跑景點，先把行李跟晚餐處理好
3. 一家五口到釜山｜旅行從最現實的事情開始
4. 晚上七點才落地｜我們的釜山第一天沒有行程

## 描述骨架

五個人的釜山旅行正式開始。

這天晚上才抵達金海機場，所以沒有硬塞夜景或景點；先把行李送到 Booking the Bay、確認隔天動線，再看五個人的體力決定吃什麼。

這支比較像整趟旅行的序章：從機場、叫車、進房，到第一晚真正安頓下來。

- 五人行李＋機場抵達牌

# 9/8｜南浦／市場／札嘎其：港區主拍攝日

## 標題方向

1. 釜山港邊走一天｜市場、風、五個人隨便吃一頓
2. 不跑景點的釜山｜南浦一路走到札嘎其
3. 五個人遊釜山｜排隊超過 40 分鐘就換店
4. 釜山舊市區慢慢走｜市場到港口的一天
5. 這次不去甘川｜我們只走釜山港邊

## 描述骨架

釜山港邊走一天的紀錄。

南浦 → 國際市場 → 富平罐頭市場 → BIFF 外圍 → 札嘎其。

我們沒有把甘川、松島、釜山塔全部塞進同一天，也沒有把生魚片當主角；主要想看看市場、港口、推車、冰、水、船跟街區本身。

五個人一起旅行，這天的規則很簡單：走累就停，排隊超過大約 40 分鐘就換，不為了一家店破壞整天。

- 市場冰塊／海鮮工作畫面＋人物半身
- 港面＋札嘎其背景＋人物
- 五人一桌吃飯的大桌面

## 標籤

釜山, Busan, 南浦, 札嘎其, 國際市場, 富平罐頭市場, 韓國自由行, 家庭旅行

# 9/9｜海雲台：把旅行速度放慢

## 標題方向

1. 昨天還在市場，今天坐在海雲台｜同一個釜山差好多
2. 五個人去海雲台｜今天不趕膠囊車
3. 釜山海邊慢慢過一天｜海雲台＋一鍋全熟海鮮
4. 不把海雲台塞滿｜坐海邊、吃海鮮，累了就回去
5. 釜山旅行第三天｜終於什麼都不想趕了

## 描述骨架

昨天還在南浦與札嘎其的市場裡走，今天換到海雲台。

這天不以「完成多少景點」為目標：先到海邊坐下，再吃一鍋五個人可以一起分的全熟海鮮；下午只在冬柏島與看海咖啡之間選一個，廣安里有體力才加。

實際去了哪些、最後有沒有取消，就以當天五個人的狀態為準。

- 第一次走到海灘的 Wide shot
- 五人坐海邊自然互動畫面
- 海鮮鍋煮滾近景＋人物反應

# 9/10｜A 線暫存：太宗台／烤貝／Spa Land

> 只有 9/10 最終仍保留舊主線才使用。若正式改走 Outlet，整組刪除。

## 標題方向

1. 釜山最看天氣的一天｜太宗台走完直接去泡湯
2. 五個人去太宗台｜走多少算多少，不硬跑完整圈
3. 海邊烤貝再去 Spa｜釜山這天專門留給體力
4. 太宗台列車不可靠？我們乾脆不把它當必要行程

## 描述骨架

這天本來就是整趟最看天氣的一天。

從太宗台看外海，午餐在影島吃烤貝／熟海鮮，下午直接去 Spa Land 把體力收回來。太宗台不以走完整圈為目標，也不把園內列車當必要條件；如果天氣或體力不適合，就提早離開。

## Thumbnail 候選

# 9/10｜B 線暫存：Busan Premium Outlets／東萊虛心廳／西面

> 目前較優候選；只有正式切線後才使用。標題不要先寫「超好買」，等實際購物結果再決定。

## 標題方向

1. 我們把景點換成 Outlet｜五個人的旅行還是大家開心比較重要
2. 釜山不去太宗台了？Outlet、老溫泉，再回西面吃肉
3. 五個人旅行臨時改行程｜原來這樣反而更順
4. 釜山郊區 Outlet 值不值得跑？我們逛完再去東萊泡湯
5. 不照打卡清單玩釜山｜今天完全照家人想去的走

## 描述骨架

原本這天安排太宗台，但五個人旅行真正重要的是大家想做什麼。

如果最後正式切成這條線，我們會先去 Busan Premium Outlets，給真的想逛 Outlet 的人足夠時間；再往東萊虛心廳泡湯，晚上回西面吃飯。

這支片的主題不是「Outlet 攻略」，而是家庭旅行怎麼在景點清單與每個人的興趣之間做取捨。

## Thumbnail 候選

- Outlet 大門＋購物袋＋人物
- 家人找到想逛品牌的自然反應
- 虛心廳外觀＋「景點換掉了」

# 9/11｜西面：最後完整一天只吃、買、收尾

## 標題方向

1. 釜山最後一天不跑景點｜西面買東西、吃最後一頓肉
2. 五個人旅行到最後｜大家只想逛街跟好好吃飯
3. 西面慢慢收尾｜這趟釜山最後一個完整晚上
4. 釜山最後一晚｜不追名店，五個人有位子比較重要
5. 沒把釜山全部跑完｜但這次反而比較記得每一天

## 描述骨架

最後一個完整旅行日留給西面。

不再跑遠，不補沒去到的景點；下午逛街、買漏掉的東西，晚餐先處理五個人的座位，再決定當天真正想吃哪一家。

這天比較像整趟旅行的收尾：回頭看哪些地方最有印象、哪些原本想去最後取消，以及五個人一起旅行到底怎麼排才比較舒服。

- 西面人潮 Wide shot＋五人背影
- 最後一頓肉上桌＋人物反應

# 9/12｜回程：旅行真正結束的那一段

## 標題方向

1. 釜山回家日｜五個人拖著行李去機場
2. 最後沒有補景點｜我們直接回家了
3. 六天釜山結束｜哪些地方最後真的有留下來
4. 一家五口釜山旅行｜回程才知道這樣排值不值得

## 描述骨架

最後一天只做一件事：去機場。

不排早市、不補景點，早餐簡單處理，確認五個人的行李與叫車後直接去金海機場。

如果素材夠，這支可以做成短尾聲；如果素材不夠，也可以直接併到 9/11 的片尾，不為了「每天一支」硬湊一集。
