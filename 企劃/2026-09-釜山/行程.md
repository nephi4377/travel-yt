# 釜山行程（現場主版）

五人｜2026/9/7–9/12｜住宿 Booking the Bay（釜山站）

> 這份只保留現場真的要執行的主線。2026-09-07 起不再主動擴張景點；家庭成員明確指定需求可取代低優先節點。

## 固定原則

- 一區一天為主；不為單一店跨區折返。
- 豬肉湯飯整趟最多一次；若 9/7 沒吃，也不把它變成後續追店任務。
- 不吃生魚片；海鮮優先全熟。
- 候位超過約 40 分鐘就換。
- 五人有人累、風大、下雨或交通不順：先刪加菜，不補課。
- YouTube 服從家庭旅行，不為補鏡頭重走或折返。

金海機場 → Booking the Bay → 有體力才吃 `별미청돼지국밥` → 回房。

KMA 2026-09-07 11:00 KST 最新有效特報仍列 **釜山前海風浪注意報**，解禁預告為 9/8 上午 09:00–12:00。這只是預告，不是保證。

- 市場、商圈與室內主線不因海上警示取消。

# 9/9（三）海雲台｜熟海鮮＋Club D Oasis

## 主線

Booking the Bay → 海雲台海水浴場 → 熟海鮮鍋 → **Club D Oasis `클럽디 오아시스`** → 海雲台簡單晚餐／回飯店。

## 建議節奏

| 時間 | 執行 |
|---|---|
| 09:00–09:30 | 飯店出發 |
| 約 10:00 | 海雲台沙灘，先坐、先休息 |
| 12:00–13:30 | `더 명품 해물탕 조개구이 회 곰장어 중동점`，全熟海鮮鍋 |
| 14:00 後 | Club D Oasis，當天下午唯一核心 |
| 晚上 | 海雲台就地簡單吃；不再跨去廣安里 |

## Club D Oasis 五人決策

- 地址：`부산광역시 해운대구 달맞이길 30`（LCT）。官方現行樓層導覽：**4F Water Park、5F Cheongsudang／Ocean View Spa、6F Theme Spa／Outdoor Terrace**；不要再用舊的「3~6층」當找路依據。
- 電話：`1566-8007`
- 成人近期價格錨點：Combo 約 ₩54,000；Spa 約 ₩33,000，實際以當天票券頁為準。
- Water Park 要泳裝＋完整遮髮帽類＋aqua shoes；Crocs、一般拖鞋／涼鞋、球鞋不算。
- **五人裝備全齊才走 Combo／Water Park；任一人裝備不齊就直接 Spa。** 不在現場為五套裝備拖時間。
- 更衣室、浴場與禁拍區不拍。

冬柏島／咖啡只在 Club D Oasis 臨時失效時才恢復；**廣安里退出主線**。
