# 釜山行程（現場主版）

五人｜2026/9/7–9/12｜住 Booking the Bay（釜山站）

> 這份只保留現場真的要執行的主線。詳細店家、價格與韓文見 `每日吃與交通.md`；熟海鮮細節見 `熟海鮮現場卡.md`；拍攝見 `每日口白.md`、`拍攝清單.md`。

## 旅行原則

- 一天只走一區，少折返。
- 豬肉湯飯整趟最多一次；若 9/7 已吃，後面不再安排。
- 不吃生魚片；海鮮以全熟為主。
- 排隊超過約 40 分鐘直接換。
- 五人走累、下雨、風大時，刪加菜，不補課。
- 9/5 起停止主動加新景點、新餐廳，只做最後確認。

# 9/7（一）抵達｜只進房、吃飯、睡覺

## 主線

金海機場 → 計程車 → Booking the Bay → 晚餐 → 回房。

### 時間感

- 19:00 落地。
- 出關、領行李、叫車後，約 20:30–21:30 到飯店。
- 不排任何景點。

### 晚餐

第一優先：`별미청돼지국밥` 別味清豬肉湯飯，作為整趟唯一一次豬肉湯飯。

若太累：便利商店回房。若想換口味且店還開：草梁中華街炸醬麵。

### 成功標準

行李進房、五人都吃到東西、知道明天怎麼走到釜山站。

# 9/8（二）南浦／舊市區／札嘎其｜主拍攝日

## 今天一塊

南浦 → 國際市場 → **富平罐頭市場** → BIFF 外圍 → 札嘎其 → 視體力決定是否走影島大橋。

> 舊版「釜田一帶」已刪除。釜田／西面市場在西面，不放進這天。

## 建議節奏

| 時間 | 內容 |
|---|---|
| 09:30 | 飯店出發 |
| 約 10:00 | 南浦開始走 |
| 11:30–13:00 | 午餐：奶奶伽倻密麵 `할매가야밀면` |
| 下午 | 國際市場、富平罐頭市場、札嘎其外圍 |
| 傍晚 | 走得動才加影島大橋 |
| 18:00–19:30 | 南浦晚餐，高基本 `고기본` 優先 |

## 現場重點

- 市場重點是生活感，不是逐店打卡。
- 札嘎其看外圍工作場景、港面、冰、水、推車；不把 2 樓生魚片中心當餐食目的地。
- 影島大橋只是加菜，有人腳痛就整段刪掉。

## 下雨

市場室內／有頂走道照走；取消橋上段。

## Spa Land

`신세계 스파랜드`

- 新世界 Centum City 1F。
- 官方現行資訊：08:00–23:00，最後入場 22:00。

## 天氣 Plan B
