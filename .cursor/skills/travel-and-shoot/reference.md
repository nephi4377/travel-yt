# 補充（需要時再讀）

## 一趟資料夾通常有什麼

| 檔 | 給誰 | 何時才要有 |
|----|------|------------|
| `README.md` | 這次誰去、日期、住哪 | 開趟就寫 |
| `行程.md` | 每天怎麼玩（要寫清楚） | 開趟就寫骨架再補滿 |
| `景點導覽.md` | 現場帶隊、為什麼這天 | 跟行程一起寫清楚 |
| `每日吃與交通.md` | 名物＋每餐三選一 | 行程骨架有了就寫 |
| `企劃.md` | 這一集拍什麼 | 確定要拍再填 |
| `拍攝清單.md` | 現場打勾 | 出門前一頁 |
| `細節.md` | 看／聽／講 | 跟清單一起 |
| `腳本.md` | 備忘，非逐字 | 可短 |
| `標題與描述.md` | 上片 | 剪完再寫 |

跟團多一個：`團行程.md`（貼旅行社表，或註待貼）。

模板在 `企劃/_模板/`。

## 選點一句話

- 合：「當地人買菜／吃飯／轉車，不是佈景。」
- 半合：「可以去，但只能換掉 X，不能加一天。」
- 不合：「錢或時間換到的是拍照，不是體驗密度。」

## 拍攝清單結構

出門前 → 定場擇一 → 主線 → 吃飯（為什麼停、碰到哪樣名物）→ 結尾擇一 → 現場不要做 → 沒拍到
